# FinanceTrack - Gestión de Gastos Personales con IA

Aplicación móvil desarrollada nativamente en Android orientada a optimizar el registro y análisis de finanzas personales para estudiantes universitarios. 

## Características Principales
* **Arquitectura:** MVVM en Kotlin.
* **Base de Datos:** Room Database  y sincronización con Firebase
* **Módulo de Visión Artificial:** Integración con Google ML Kit para la extracción automatizada de datos desde comprobantes físicos.
* **Asistente NLP:** Procesamiento de lenguaje natural para recomendaciones financieras interactivas.

## Requisitos del Sistema
* Android 8.0 o superior.
* Conexión a internet para las funciones de IA y sincronización

## Proyecto Académico
Desarrollado para la asignatura Proyecto Integrador II - Ingeniería de Sistemas.
